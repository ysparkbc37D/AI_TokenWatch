Claude 사용 한도 연동 원리

Claude.ai는 공식 REST API 대신 5시간/주간 롤링 세션 윈도우를 사용합니다. 화면 우측 상단의 [수정] 버튼으로 현재 claude.ai에 표시된 %와 시간을 입력해 두시면, 본 대시보드가 1초 단위로 리셋 시점을 추적하며 알림을 울려줍니다.

Gemini & Antigravity 연동 원리

Antigravity IDE의 Gemini Models / Claude & GPT / Argon 쿼터 역시 세션 단위로 실시간 갱신됩니다. 현재 잔여량(left %)을 설정해 두시면 실시간 카운트다운 타이머가 초기화 일정을 시각화합니다.

💡 왜 기본 브라우저에서는 완전 자동 감지가 안 되나요?
크롬 브라우저의 보안 규칙(동일 출처 정책)으로 인해, http://localhost:8089 탭은 사용자가 claude.ai 탭이나 Antigravity에서 무엇을 입력하는지 임의로 엿볼 수 없습니다.
아래의 실시간 브릿지(Bridge)를 통해 사용 즉시 1초 만에 자동 반영되도록 만들 수 있습니다!

1 Claude.ai 원클릭 북마클릿 (가장 간편!)

추천

Claude 웹사이트(claude.ai)에서 질문 후 브라우저 즐겨찾기(북마클릿)를 누르면, 현재 사용량 수치를 즉시 로컬 서버(/api/quota)로 쏴서 대시보드가 새로고침 없이 즉시 갱신됩니다.

javascript:(function(){var p=prompt("현재 5시간 사용량 %(예: 35)를 입력하세요","35");if(p){fetch('http://localhost:8089/api/quota',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({claude:{fiveHourPct:parseInt(p)}})}).then(r=>alert('⚡ 대시보드 실시간 반영 완료!'));}})();

위 코드를 브라우저 북마크 URL에 추가해두고 claude.ai 탭에서 누르면 1초 만에 전송됩니다.

2 터미널 한 줄 명령으로 실시간 갱신

PowerShell 터미널에서 질문 후 아래 명령 한 줄을 치면 대시보드 화면이 실시간으로 바뀝니다:

Invoke-RestMethod -Uri "http://localhost:8089/api/quota" -Method POST -Body '{"claude":{"fiveHourPct":40}}'

3 대시보드 자체의 '+5% 사용' 버튼 클릭

별도 설정 없이도 각 카드 하단의 [+5% 사용] 버튼을 누르면 대화 횟수에 비례하여 게이지가 즉시 오르며, 초기화 시간(카운트다운)은 컴퓨터 시계와 1초 단위로 완벽하게 연동됩니다.
